# Dutch Flashcards
Anki-style SM-2 flashcards for the most common Dutch words. Native audio: edge-tts nl-NL-FennaNeural. Extend by adding entries to deck.json. "Phrases this week" (family & everyday) deck lives in phrases.json (ids p01…), selectable via the deck tabs (1 · Top words, then 2 · Phrases; the old Both option was removed and saved "both" falls back to Top words). Listening cards for words say the word, pause 700 ms, then the sentence (study.js). "Say it" speaking practice (Settings → Speaking practice): Web Speech API nl-NL; on EN→NL cards a Correct/Close match reveals the answer, otherwise it is pronunciation practice once the Dutch is shown. Matching lives in say.js; Weak cards drill (done screen and Settings): cards forgotten 2+ times (saved `lapses`), worst first, max 15, graded with the normal buttons using the review-ahead rule so intervals never jump; Again brings a card back once at the end. Tests: `node --test test/*.test.js`.
