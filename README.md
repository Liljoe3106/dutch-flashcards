# Dutch Flashcards
Anki-style SM-2 flashcards for the most common Dutch words. Native audio: edge-tts nl-NL-FennaNeural. Extend by adding entries to deck.json. "Phrases this week" (family & everyday) deck lives in phrases.json (ids p01…), selectable via the deck tabs; Both shows phrases first. "Say it" speaking practice (Settings → Speaking practice): Web Speech API nl-NL; on EN→NL cards a Correct/Close match reveals the answer, otherwise it is pronunciation practice once the Dutch is shown. Matching lives in say.js; tests: `node --test test/`.
